# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for `embr`.

ADRs capture design decisions that shape the codebase over time. They are not
implementation guides or exhaustive documentation. Each ADR records the context,
the decision, the tradeoffs, and the alternatives considered.
